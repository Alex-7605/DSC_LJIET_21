# Example CSVs

Both files in this folder are small **synthetic teaching fixtures**, authored for this project and distributed under the repository's MIT terms. They are not Olist records or evidence about a real business.

- general_example.csv: a non-delivery schema for the universal exploration path.
- delivery_template.csv: on-time, late and cancelled demonstration orders for explicit delivery mapping.

The actual real-data sample and its separate CC BY-NC-SA 4.0 license live in data/sample/.
