Accessed: 1 November 2026.

The included real-data sample is an adaptation distributed under that same license. Changes: fixed-seed 12,000-order sample; item-price aggregation to order grain; English category translation; multi-category labels; removal of customer identifiers, fine locations and text; replacement of order linkage hashes.

Data-derived summaries, model-evaluation results, exported reports, screenshots containing source data and trained sample artifacts should be treated under the same dataset terms. Preserve attribution, state modifications, restrict data use to non-commercial purposes and share adaptations under the same license. This repository is a non-commercial educational project and is not affiliated with Olist.

Original application code is separately MIT licensed. No private/raw customer data, Kaggle credentials or model-upload support is included.

The DataCo dataset was considered but not selected. Its shipping-duration semantics would not justify silently treating shipment as actual customer arrival.
