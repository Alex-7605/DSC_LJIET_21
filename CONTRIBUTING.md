# Contributing

Use Python 3.14 and a virtual environment. Install requirements.txt, run python -m pytest -q and describe the behavior change with a small reproducible example.

Keep central metrics consistent across cards, charts, reports and insights. Preserve order boundaries and the placement-time feature allowlist. Never tune against the final test labels. Document a changed target or split protocol before retraining. Use non-sensitive test fixtures and respect the Olist data license.

For a pull request, include the concrete problem, resulting behavior, relevant checks and any limitation that remains.
